# Exact 27-point `C3` product negative control

Status: `EXACT_NONCONVEX_NEGATIVE_CONTROL` / exact algebraic certificate.

This note instantiates the full-orbit projective version of the product
template from `docs/c3-nonconvex-control.md` with two exact three-step cycles.
The resulting 27 distinct points give every point four exact equidistant
partners, but only 18 points are convex-hull vertices. It is therefore not a
counterexample to Erdos Problem #97 and does not change the repository or
official/global status.

## Multiplier circle and projective cycles

Let

```text
omega = exp(2*pi*i/3)
```

and parametrize the multiplier circle by

```text
X(t) = 1 + sqrt(3)*(1+i*t)/(1-i*t),  t real.
```

Then

```text
|X(t)-1|^2 = 3.
```

Define `u_A` and `u_B` to be the lower real roots of

```text
(-75+44*sqrt(3))*u^2 + (-18+6*sqrt(3))*u - 33-14*sqrt(3) = 0,
(-162+96*sqrt(3))*u^2 + (-32+16*sqrt(3))*u - 50-16*sqrt(3) = 0,
```

respectively. Numerically, only for orientation,

```text
u_A = -4.4188556688106378501...
u_B = -3.7908411282773678551...
```

For the first cycle put

```text
r_A0 = X(2),
r_A1 = X(u_A),
r_A2 = omega/(r_A0*r_A1),

a_0 = 1,
a_1 = r_A0,
a_2 = r_A0*r_A1.
```

For the second cycle use the same definitions with `2,u_A,a` replaced by
`3,u_B,b`. The defining quadratics are exactly the conditions

```text
|r_A2-1|^2 = |r_B2-1|^2 = 3.
```

Thus every multiplier lies on `|lambda-1|^2=3`, while

```text
r_A0*r_A1*r_A2 = r_B0*r_B1*r_B2 = omega.
```

The cycles close projectively rather than as literal representative cycles:

```text
r_A2*a_2 = omega*a_0,
r_B2*b_2 = omega*b_0.
```

That monodromy is important. A full `C3` orbit identifies representatives up
to multiplication by `omega`, so the last step is a valid successor in the
lift. Treating the representative cycle as having product one would remove
this branch incorrectly.

The exact checker also verifies that each factor lift

```text
A = {a_i*omega^k : 0 <= i,k < 3},
B = {b_j*omega^k : 0 <= j,k < 3}
```

has nine distinct strict hull vertices. Every factor point has its two orbit
mates and one projective-cycle successor at the common distance
`sqrt(3)` times its modulus. These are exact Danzer-style three-rich
nonagons, not merely numerical seeds.

## The 27-point product

Set

```text
P = {a_i*b_j*omega^k : 0 <= i,j,k < 3}.
```

Write `p_ijk=a_i*b_j*omega^k`. Its four named witnesses are

```text
p_i,j,k+1,
p_i,j,k+2,
p_i+1,j,k,
p_i,j+1,k,
```

where phase indices are modulo three, and a wrapped first or second cycle
increments the phase by one. The first two distances are the same-orbit
identity

```text
|p_ijk - omega*p_ijk|^2 = |p_ijk - omega^2*p_ijk|^2
                         = 3*|p_ijk|^2.
```

For a cycle successor with multiplier `r`,

```text
|r*p_ijk - p_ijk|^2 = |r-1|^2*|p_ijk|^2
                     = 3*|p_ijk|^2.
```

Therefore every point has four exact partners at one center-dependent
distance. The checker verifies all 108 named squared-distance equalities.

The nine product orbit representatives `a_i*b_j` have pairwise distinct
squared moduli. Consequently their full `C3` lifts are disjoint and `P` has
exactly 27 distinct points.

## Exact convex-hull failure

Using labels `(i,j,k)`, the exact hull has 18 vertices. The nine strict
interior labels are

```text
(0,0,0), (0,0,1), (0,0,2),
(0,2,0), (0,2,1), (0,2,2),
(2,0,0), (2,0,1), (2,0,2).
```

The checker does not infer this from floating-point geometry. It reconstructs
the coordinates in the real algebraic field generated by

```text
sqrt(3),
sqrt(-519+348*sqrt(3)),
sqrt(-761+488*sqrt(3)),
```

then verifies every asserted hull-edge half-plane sign in the selected real
embedding. All nine omitted points lie strictly inside every relevant hull
supporting half-plane.

## Scope

This construction is an exact metric negative control and a concrete closure
of one product-template branch. It does not establish that every realization
of the product template is nonconvex, obstruct longer projective cycles,
classify other monodromies, or rule out perturbations with different witness
assignments. It proves neither Erdos Problem #97 nor a counterexample.
